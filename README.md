🥤 DEVCLUB Refrigerante

📋 Sobre o Projeto

O DEVCLUB Refrigerante é uma aplicação web interativa desenvolvida durante os estudos de Front-End no DEVClub.

O projeto simula uma apresentação moderna de produtos, permitindo ao usuário navegar entre diferentes sabores de refrigerante através de um carrossel animado. A cada interação, o sistema altera dinamicamente o fundo, os textos e as imagens, proporcionando uma experiência visual envolvente e profissional.

O objetivo principal foi praticar conceitos fundamentais de desenvolvimento Front-End, incluindo manipulação do DOM, animações, transições e responsividade.
